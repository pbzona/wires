This tutorial builds a four-bit ripple-carry adder from the standard [`FullAdder`](/library/arithmetic), using only the public API. The result is 60 NAND gates, organized as a hierarchy you can inspect.

<Steps>
  <Step title="Define the ports">
    Two four-bit operands (`a0`–`a3` and `b0`–`b3`, least significant bit first), a carry in, four sum bits and a carry out.
  </Step>

  <Step title="Chain the full adders">
    Each stage's carry out feeds the next stage's carry in. `carry` starts at `chip.inputs.carryIn`. On each pass, `chip.add` wires it to one stage and `chip.output` connects that stage's sum to the matching output pin. The stage's carry out becomes the source for the next pass.

    ```ts
    import { circuit, type SourcePort } from "@pbzona/wires";
    import { FullAdder } from "@pbzona/wires/components";

    export const Adder4 = circuit(
      {
        name: "Adder4",
        inputs: ["a0", "a1", "a2", "a3", "b0", "b1", "b2", "b3", "carryIn"],
        outputs: ["s0", "s1", "s2", "s3", "carryOut"],
      },
      (chip) => {
        let carry: SourcePort = chip.inputs.carryIn;
        for (const i of [0, 1, 2, 3] as const) {
          const stage = chip.add(FullAdder, `fa${i}`, {
            a: chip.inputs[`a${i}`],
            b: chip.inputs[`b${i}`],
            carryIn: carry,
          });
          chip.output(`s${i}`, stage.outputs.sum);
          carry = stage.outputs.carryOut;
        }
        chip.output("carryOut", carry);
      },
    );
    ```

    The template literal keys like `` chip.inputs[`a${i}`] `` are still type-checked, because `i` is the literal union `0 | 1 | 2 | 3`.
  </Step>

  <Step title="Add some numbers">
    ```ts
    import { circuit, simulate, type Signal, type SourcePort } from "@pbzona/wires";
    import { FullAdder } from "@pbzona/wires/components";

    const Adder4 = circuit(
      {
        name: "Adder4",
        inputs: ["a0", "a1", "a2", "a3", "b0", "b1", "b2", "b3", "carryIn"],
        outputs: ["s0", "s1", "s2", "s3", "carryOut"],
      },
      (chip) => {
        let carry: SourcePort = chip.inputs.carryIn;
        for (const i of [0, 1, 2, 3] as const) {
          const stage = chip.add(FullAdder, `fa${i}`, {
            a: chip.inputs[`a${i}`],
            b: chip.inputs[`b${i}`],
            carryIn: carry,
          });
          chip.output(`s${i}`, stage.outputs.sum);
          carry = stage.outputs.carryOut;
        }
        chip.output("carryOut", carry);
      },
    );

    const operandPins = (prefix: "a" | "b", n: number) =>
      Object.fromEntries([0, 1, 2, 3].map((i) => [`${prefix}${i}`, ((n >> i) & 1) as Signal]));

    let sim = simulate(Adder4);
    for (const [a, b] of [[3, 4], [7, 9], [15, 15]] as const) {
      const before = sim.set({ ...operandPins("a", a), ...operandPins("b", b), carryIn: 0 });
      sim = before.run();
      const { s0, s1, s2, s3, carryOut } = sim.readAll();
      const sum = [s0, s1, s2, s3, carryOut].reduce<number>((total, bit, i) => total + Number(bit) * 2 ** i, 0);
      console.log(`${a} + ${b} = ${sum} (settled in ${sim.tick - before.tick} ticks)`);
    }
    ```

    ```text
    3 + 4 = 7 (settled in 15 ticks)
    7 + 9 = 16 (settled in 17 ticks)
    15 + 15 = 30 (settled in 7 ticks)
    ```

    The settle time depends on how far the carry has to ripple from the previous input.
  </Step>

  <Step title="Test every combination">
    With 4 + 4 + 1 input bits there are only 512 cases, so you can check them all:

    ```ts
    for (let a = 0; a < 16; a++) {
      for (let b = 0; b < 16; b++) {
        for (const carryIn of [0, 1] as const) {
          sim = sim.set({ ...operandPins("a", a), ...operandPins("b", b), carryIn }).run();
          const { s0, s1, s2, s3, carryOut } = sim.readAll();
          const sum = [s0, s1, s2, s3, carryOut].reduce<number>((total, bit, i) => total + Number(bit) * 2 ** i, 0);
          if (sum !== a + b + carryIn) throw new Error(`${a} + ${b} + ${carryIn} gave ${sum}`);
        }
      }
    }
    ```

    The library's own test suite runs exactly this check.
  </Step>

  <Step title="Look inside">
    [`elaborate()`](/reference/elaborate) flattens the hierarchy into primitive gates. The instance names `fa0` through `fa3` let you tell which stage a gate belongs to. For example, the final carry comes from the NAND inside the last stage's OR:

    ```ts
    const netlist = elaborate(Adder4); // import { elaborate } from "@pbzona/wires"
    console.log(netlist.gates.length); // 60
    console.log(netlist.outputs.carryOut); // "root.fa3.or.nand.outputs.out"
    ```

    Each full adder is two half adders (an XOR of 4 NANDs plus an AND of 2) and an OR of 3 NANDs, which comes to 15 NANDs per bit.
  </Step>
</Steps>
