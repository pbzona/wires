---
title: "simulate()"
description: "Start a simulation and work with its immutable states."
icon: "play"
---

```ts
function simulate<I extends string, O extends string>(
  definition: ComponentDefinition<I, O>,
  options?: SimulationOptions,
): SimulationState<I, O>;
```

Elaborates the definition (cached per definition) and returns the first state of a new simulation: tick 0, every signal `"X"`, and every gate due for its first evaluation.

## Options

Options are fixed when the simulation starts and carry over to every later state.

<ResponseField name="maxTicks" type="number" default="10000">
  The maximum number of steps a single `run()` call may take. Must be a positive integer.
</ResponseField>

<ResponseField name="trace" type="boolean" default="false">
  Record every wire change, so `trace()` can return it.
</ResponseField>

## SimulationState

A frozen object describing one moment of the simulation. Methods that move the simulation forward return a **new** state and never change the one they're called on.

### Properties

<ResponseField name="tick" type="number">
  Simulation time: the next tick to be processed.
</ResponseField>

<ResponseField name="stable" type="boolean">
  True when no wire changes are pending and every gate has had its first evaluation.
</ResponseField>

<ResponseField name="changes" type="readonly SignalTransition[]">
  The wire changes applied by the step that produced this state, in wire order. Empty for the first state and for states returned by `set()`.
</ResponseField>

### Moving forward

<ResponseField name="set(inputs)" type="(inputs: { [K in I]?: Signal }) => SimulationState">
  A new state with these external inputs pending. They take effect on the next step. Returns the same state if nothing would change. Throws `SimulationError` for unknown names or invalid values, without applying anything.
</ResponseField>

<ResponseField name="step()" type="() => SimulationState">
  A new state, one tick later. It applies the pending changes, evaluates the gates that read a changed wire, and makes their changed outputs pending.
</ResponseField>

<ResponseField name="run()" type="() => SimulationState">
  A new state, stepped until stable. Returns the same state if it's already stable. Throws `StabilizationError` after `maxTicks` steps.
</ResponseField>

### Reading

<ResponseField name="read(output)" type="(output: O) => Signal">
  The current value of one external output.
</ResponseField>

<ResponseField name="readAll()" type="() => { [K in O]: Signal }">
  The current values of all external outputs.
</ResponseField>

<ResponseField name="inspect()" type="() => SimulationSnapshot">
  Plain, serializable data: `{ tick, stable, pendingEvents, signals, wires }`. `signals` maps every hierarchical port id to its value, and `wires` maps every wire id to `{ value, ports }`.
</ResponseField>

<ResponseField name="trace()" type="() => readonly SignalTransition[]">
  A frozen array of every wire change from tick 0 up to this state, ordered by tick and then by wire id. Empty unless `trace: true`.
</ResponseField>

## Example

```ts
import { simulate } from "@pbzona/wires";
import { AND } from "@pbzona/wires/components";

const start = simulate(AND);
const settled = start.set({ a: 1, b: 1 }).run();

console.log(settled.read("out")); // 1
console.log(settled.tick - start.tick); // 3 ticks to settle
console.log(start.read("out")); // "X": start never changes
```

## Related types

```ts
type SimulationOptions = {
  readonly maxTicks?: number;
  readonly trace?: boolean;
};

type SimulationSnapshot = {
  readonly tick: number;
  readonly stable: boolean;
  readonly pendingEvents: number;
  readonly signals: Readonly<Record<string, Signal>>;
  readonly wires: Readonly<Record<string, { readonly value: Signal; readonly ports: readonly string[] }>>;
};
```
