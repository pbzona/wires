## SRLatch

A set-reset latch made of two cross-coupled NAND gates, with **active-low** controls. Children: `top` (drives `q`) and `bottom` (drives `qBar`).

| setN | resetN | q | qBar | Meaning |
| --- | --- | --- | --- | --- |
| 0 | 1 | 1 | 0 | Set |
| 1 | 0 | 0 | 1 | Reset |
| 1 | 1 | q | qBar | Hold (`X` until first set or reset) |
| 0 | 0 | 1 | 1 | Forbidden: not a valid stored state |

```ts
import { simulate } from "@pbzona/wires";
import { SRLatch } from "@pbzona/wires/components";

const latch = simulate(SRLatch)
  .set({ setN: 0, resetN: 1 }) // set
  .run()
  .set({ setN: 1 }) // release
  .run();
console.log(latch.readAll()); // { q: 1, qBar: 0 }: the bit is retained
```

<Warning>
  Releasing both controls from `0, 0` to `1, 1` in the same tick makes both gates toggle together forever. `run()` reports this with a `StabilizationError` instead of picking a winner. Release one control before the other.
</Warning>

See [Sequential logic](/guides/sequential-logic) for a full walkthrough.

## RegisterBit

`RegisterBit` stores `d` on the rising edge of `clock` when `load` is `1`. With `load` set to `0`, it holds `q` instead. While `clock` is low, the first latch tracks the selected value; when `clock` rises, the second latch passes that value to `q`. The change takes time to propagate through the NAND gates.

```ts
import { simulate } from "@pbzona/wires";
import { RegisterBit } from "@pbzona/wires/components";

const ready = simulate(RegisterBit).set({ d: 1, clock: 0, load: 1 }).run();
console.log(ready.read("q")); // "X": nothing has been stored yet
const stored = ready.set({ clock: 1 }).run();
console.log(stored.read("q")); // 1
```

Settle the data and load control with the clock low before raising it. To store several bits on the same clock, build an [eight-bit register](/guides/eight-bit-register) from these cells.
