## Install

<CodeGroup>

```bash pnpm
pnpm add @pbzona/wires
```

```bash npm
npm install @pbzona/wires
```

```bash bun
bun add @pbzona/wires
```

</CodeGroup>

`wires` is published on npm as `@pbzona/wires`. It needs Node.js 24, or 26 and later (no end-of-life releases), Bun, or any modern browser or bundler, and it has no runtime dependencies. The package has two entry points:

| Import | Contents |
| --- | --- |
| `@pbzona/wires` | The engine: `gate`, `circuit`, `simulate`, `elaborate`, errors and types |
| `@pbzona/wires/components` | The standard library: `NAND`, `NOT`, `AND`, `OR`, `NOR`, `XOR`, `XNOR`, `HalfAdder`, `FullAdder`, `Mux`, `Demux`, `SRLatch` |

## Build and simulate a circuit

<Steps>
  <Step title="Define a primitive gate">
    A primitive has an explicit evaluation function. Here is NAND, the only gate you need to build everything else.

    ```ts
    import { gate } from "@pbzona/wires";

    export const NAND = gate({
      name: "NAND",
      inputs: ["a", "b"],
      outputs: ["out"],
      evaluate: ({ a, b }) => ({
        out: a === 0 || b === 0 ? 1 : a === 1 && b === 1 ? 0 : "X",
      }),
    });
    ```

    `@pbzona/wires/components` exports this exact gate, so the next steps import it from there.
  </Step>

  <Step title="Compose it into a circuit">
    A composite circuit adds parts one at a time, saying what feeds each part's inputs, then says what drives its outputs.

    ```ts
    import { circuit } from "@pbzona/wires";
    import { NAND } from "@pbzona/wires/components";

    export const AND = circuit(
      { name: "AND", inputs: ["a", "b"], outputs: ["out"] },
      ({ inputs, add, output }) => {
        const nand = add(NAND, "nand", { a: inputs.a, b: inputs.b });
        const not = add(NAND, "not", { a: nand.outputs.out, b: nand.outputs.out });
        output("out", not.outputs.out);
      },
    );
    ```

    Read it top to bottom: the inputs feed `nand`, `nand` feeds `not` (a NAND with both inputs tied together is a NOT), and `not` drives the output.
  </Step>

  <Step title="Simulate it">
    A simulation is a sequence of states. `simulate()` gives you the first one, and `set()` and `run()` each return a new state. The old state never changes.

    ```ts
    import { simulate } from "@pbzona/wires";
    import { AND } from "@pbzona/wires/components";

    let sim = simulate(AND);

    sim = sim.set({ a: 1, b: 1 }).run();
    console.log(sim.read("out")); // 1

    sim = sim.set({ a: 0 }).run();
    console.log(sim.read("out")); // 0
    ```

    Time only moves when you call `run()` (or `step()`, which moves one tick).
  </Step>

  <Step title="Look inside">
    Every state can report the value of every port in the hierarchy, and with tracing on, every change that led to it.

    ```ts
    import { simulate } from "@pbzona/wires";
    import { AND } from "@pbzona/wires/components";

    const settled = simulate(AND, { trace: true }).set({ a: 1, b: 1 }).run();

    console.log(settled.inspect().signals["root.nand.outputs.out"]); // 0
    console.log(settled.trace().length); // 4 wire changes
    ```
  </Step>
</Steps>

<Tip>
  Port names are inferred from your definitions. `settled.read("nope")` or `add(NAND, "nand", { c: inputs.a })` fails at compile time, not at runtime.
</Tip>
