## Install

<CodeGroup>

```bash pnpm
pnpm add @pbzona/wires
```

```bash npm
npm install @pbzona/wires
```

```bash bun
bun add @pbzona/wires
```

</CodeGroup>

`wires` is published on npm as `@pbzona/wires`. It needs Node.js 24, or 26 and later (no end-of-life releases), Bun, or any modern browser or bundler, and it has no runtime dependencies. The package has two entry points:

| Import | Contents |
| --- | --- |
| `@pbzona/wires` | The engine: `gate`, `circuit`, `bits`, `simulate`, `elaborate`, errors and types |
| `@pbzona/wires/components` | The standard library: `NAND`, `NOT`, `AND`, `OR`, `NOR`, `XOR`, `XNOR`, `HalfAdder`, `FullAdder`, `Mux`, `Demux`, `SRLatch`, `RegisterBit` |

## Build and simulate a circuit

<Steps>
  <Step title="Define a primitive gate">
    A primitive computes values. When the simulator evaluates NAND, `a` and `b` are signal values (`0`, `1` or `"X"`), and `out` is the value the gate produces.

    ```ts
    import { gate } from "@pbzona/wires";

    export const NAND = gate({
      name: "NAND",
      inputs: ["a", "b"],
      outputs: ["out"],
      evaluate: ({ a, b }) => ({
        out: a === 0 || b === 0 ? 1 : a === 1 && b === 1 ? 0 : "X",
      }),
    });
    ```

    The next example runs on its own. It imports this same NAND gate from `@pbzona/wires/components`.
  </Step>

  <Step title="Build NOT, then use it to build AND">
    A circuit connects wires. To build NOT, feed its `a` pin to both NAND inputs. To build AND, feed `a` and `b` to a NAND, then invert its result with the NOT you just built.

    ```ts
    import { circuit, simulate } from "@pbzona/wires";
    import { NAND } from "@pbzona/wires/components";

    const NOT = circuit(
      { name: "NOT", inputs: ["a"], outputs: ["out"] },
      (chip) => {
        const nand = chip.add(NAND, { a: chip.inputs.a, b: chip.inputs.a });
        chip.output("out", nand.outputs.out);
      },
    );

    const AND = circuit(
      { name: "AND", inputs: ["a", "b"], outputs: ["out"] },
      (chip) => {
        const nand = chip.add(NAND, { a: chip.inputs.a, b: chip.inputs.b });
        const inverter = chip.add(NOT, { a: nand.outputs.out });
        chip.output("out", inverter.outputs.out);
      },
    );

    const sim = simulate(AND).set({ a: 1, b: 1 }).run();
    console.log(sim.read("out")); // 1
    console.log(sim.set({ b: 0 }).run().read("out")); // 0
    ```

    `chip` is the builder for the gate you're defining. Inside AND, `chip.add(NOT, …)` wires your NOT the same way `chip.add(NAND, …)` wires a primitive. You don't need to repeat the wiring inside NOT.

    `set()` queues a change; `run()` advances time until the circuit settles. Both return new states. To see the gate delays, [step through a simulation](/guides/running-simulations) or [trace a wire](/guides/introspection#trace).
  </Step>
</Steps>

<Tip>
  Use the pin names you'd put on a circuit diagram. `a`, `b` and `out` suit AND; a half adder calls its two outputs `sum` and `carry` because they do different jobs.
</Tip>

Optional exercise: build a ready light with one input, `busy`, and one output, `lit`. Use your NOT as the only part. What should `lit` read when `busy` is `0`?
